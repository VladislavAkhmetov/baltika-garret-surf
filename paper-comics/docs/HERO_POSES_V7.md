# Повороты и трюки серфера, v7

Согласованная базовая стойка v6 сохранена. Встроенным ImageGen созданы шесть отдельных прозрачных ключевых поз того же персонажа. Исходники находятся в `assets/comics/hero-v7/`; точные полные промпты — в [generation.json](../assets/comics/hero-v7/generation.json).

| Файл | Использование |
|---|---|
| `carve-left.png` | Активная фаза левого поворота |
| `carve-right.png` | Активная фаза правого поворота |
| `compress.png` | Приседание, подготовка к прыжку, выход из приземления |
| `air.png` | Полёт, раскрытие после вращения, восстановление равновесия |
| `trick.png` | Группировка во время существующих вращений |
| `landing.png` | Начало амортизации при приземлении |

Это шесть новых ключевых изображений, а не 56 независимо нарисованных кадров. Вместе с базой они образуют семь игровых последовательностей по восемь кадров. Небольшое вторичное движение добавляется существующим деформатором; области стоп исключены из него. Повороты используют разные фотографии, а не зеркальное отражение персонажа.

Все изображения вписаны с сохранением пропорций в общий размер. Масштаб группировки равномерно уменьшен до 0,82 для согласования размера головы с базой. Точки хвата и подошв размечены отдельно для каждого источника в `HeroAnimator.poseDefinitions`. Доска подбирает угол под проекцию стойки; кружка следует за кистью и остаётся отдельным объектом с динамическими пивом, пеной и проливом. Вертикальное сжатие всего персонажа при приземлении убрано.

## Проверка

`npm run test:hero-grip` проверяет все 56 кадров: контакты стоп с доской, совпадение точки хвата с ручкой, порядок слоёв, переключение полёта/группировки/приземления, движение жидкости, пролив, сброс, четыре размера экрана и обе входные страницы. Превью и отчёт сохраняются в `review/comics/hero-poses-v7/`.

`npm run test:prototype` и `npm run test:airwaves` проверяют управление и существующий игровой цикл прыжков и вращений. Художественная оценка переходов дополнительно выполняется по игровым превью: геометрический тест сам по себе не доказывает естественность анатомии.
