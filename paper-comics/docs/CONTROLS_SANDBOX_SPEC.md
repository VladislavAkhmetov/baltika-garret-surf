> Для агента-исполнителя. Цель — НЕ уровень, а отдельная страница `sandbox.html`, где заказчик на реальном телефоне подбирает ощущение управления ползунками. Только после утверждения пресета переписываем уровень.

## 0. Новая механика в одном абзаце

Полос нет — сёрфер свободно движется по ширине трассы. Слева вдоль трассы катится длинная **ломающаяся волна** (как у настоящих сёрферов): чем ближе к гребню — тем быстрее, но тем круче склон и выше риск, что накроет. Справа — спокойное «плечо» волны и зыбь.
- **Наклон телефона = поворот (карвинг).** Наклонил и держишь — сёрфер плавно уходит в сторону.
- **Пиво плещет не от наклона, а от резкости.** В вираже сёрфер наклоняется вместе с кружкой, и жидкость остаётся ровной (как стакан на подносе у официанта в повороте). Плещет от рывков туда-сюда, ударов, кильватера соперников, кочек и плохих посадок.
- **Палец (в любом месте экрана): держишь — присед, отпускаешь — прыжок.** Присед на спуске со зыби разгоняет («накачка»), отпуск у гребня — вылет в воздух.
- **В воздухе наклон телефона крутит доску** (трюк), держание пальца = грэб. Приземлиться ровно — «ЧИСТО!».

Референсы ощущения: Riptide GP (наклон-руление по воде), Kelly Slater's Pro Surfer / Surf World Series (карман у гребня = скорость), Tiny Wings (накачка по склонам), Alto's Odyssey (держать/отпустить, посадка), Wave Race 64 (вода как физика).

## 2. Мир песочницы

- Прямая трасса, бесконечная (зацикливание по Z, как `OceanLanes`). Ширина трассы `x ∈ [0, 16] м`: `x = 0` — подошва склона волны (карман), `x = 16` — дальнее плечо. Камера и всё «лево/право» — по экрану.
- Трасса разбита на повторяющийся цикл 900 м:
  | Метры цикла | Зона | Что тестируем |
  |---|---|---|
  | 0–300 | **Волна** (PeelingWave активна) | карман, скорость, обрушение гребня |
  | 300–550 | **Зыбь** (3 гребня по 40 м длины, высота 1.2 м) | накачка присед/отпуск |
  | 550–700 | **Трамплины** (3 шт., разные x) + 6 буйков | прыжки, трюки, посадки |
  | 700–900 | **Соперник-бот** едет впереди, + рябь | кильватер, обгон, толчок |
- Кнопка в панели «зона: Волна/Зыбь/Трамплины/Соперник» — телепорт в начало зоны.

### 2.1 PeelingWave (`js/peel-wave.js`)
- Склон волны — поверхность над `x ∈ [−6, 4]`: высота `face(x) = H · smoothstep(4, −6, x)`, `H = 3.2 м`. Сёрфер на склоне стоит выше и сильнее накренён (нормаль поверхности).
- Гребень (lip) — бумажная полоса пены по верхней кромке `x ≈ −5`, шевелится.
- **Обрушение:** «точка ломки» волны движется вперёд вместе с игроком со скоростью `peelSpeed` (по умолчанию = базовая скорость игрока). Позади неё — белая пена (стена `foam_wall`), которая накрывает склон.
  - Если игрок отстал (точка ломки догнала его по Z) и он в `x < 3` → **накрыло**: спотыкание (§4.7).
  - Каждые 6–10 с — **«выброс губы»**: участок гребня длиной 12 м впереди игрока на 1.2 с с предупреждением (тень + треск) падает на склон в зоне `x < 1`. Попал — накрыло.
- `getSurface(x, z) → { height, slope /*рад, крен поверхности*/, inPocket /*0..1*/ }`. `inPocket = clamp(1 − x / pocketWidth, 0, 1)`, `pocketWidth = 4 м`.
- Визуал: использовать текущий бумажный стиль, склон — слои рваной бумаги `--ocean-mid → --ocean-light` с белым гребнем. Заглушки допустимы.

## 3. Ввод (`js/control-input.js`)

Выход: `{ lean /* −1..1 */, hold /*bool*/, holdTime /*с*/, released /*событие*/, mode }`.

**Гироскоп (основной):**
- Калибровка 3-2-1 «держи телефон ровно» → `neutralGamma`.
- `rel = gamma − neutral`, мёртвая зона `leanDeadzone` (1.5°), low-pass `leanAlpha` (0.45).
- `lean = clamp(rel / leanRange, −1, 1)`, `leanRange` = 25°. Кривая отклика `lean = sign · |lean|^leanCurve`, `leanCurve` = 1.3 (мягко в центре, резко на краях).

**Палец:** касание в любом месте = `hold`, отпускание = `released` (с `holdTime`). Мультитач не нужен.

**Фолбэк без гироскопа:** горизонтальный drag от точки касания = `lean` (`dx / 80px`, клэмп ±1), т.е. касание = одновременно hold. Чтобы разделить: в фолбэке экран делится пополам — **левая половина: drag = наклон**, **правая: hold/release**. Подписи-призраки на экране при первом запуске.

**Клавиатура:** ←/→ — `lean` (плавный набор 0→1 за 0.25 с), Пробел — hold/release.

## 4. Физика сёрфера (`js/surf-physics.js`)

Все константы — в `CFG.surf` и на панели (§6). Фиксированный шаг 1/120 с.

### 4.1 Курс и движение
- Состояние: `x, z, heading /*рад, 0 = прямо*/, speed, vy, airY, airborne, spin, crouch /*0..1*/`.
- Поворот: `headingTarget = lean · maxHeading` (`maxHeading` = 38°). `heading += (headingTarget − heading) · (1 − exp(−turnRate · dt))`, `turnRate` = 6.
- Движение: `x += sin(heading) · speed · lateralScale · dt` (`lateralScale` = 0.35 — иначе ширину пролетаешь мгновенно), `z += cos(heading) · speed · dt`.
- Края: `x < −5` — упор в гребень (мягкая стена + выброс пены), `x > 16` — мягкая стена.
- Крен сёрфера (визуал): `roll = lean · 28° + surface.slope`.

### 4.2 Скорость
```
speed → target, где
target = baseSpeed
       · (1 + pocketBoost · inPocket)          // карман: до +40%
       · (1 − carveDrag · |heading| / maxHeading) // резкий вираж тормозит: до −12%
       + pumpBonus                               // накачка, затухает
       + wakeBonus                               // кильватер
speed += (target − speed) · (1 − exp(−speedResponse · dt))
```
`baseSpeed` 26 → 34 по ходу (как в ТЗ уровня), `pocketBoost` 0.40, `carveDrag` 0.12, `speedResponse` 1.5.

### 4.3 Накачка (зыбь)
- На склоне зыби: если `hold` (присед) пока поверхность идёт **вниз** (`dh/dz < 0`) → `pumpBonus += pumpGain · |dh/dz| · dt`.
- Если `hold` на подъёме → `pumpBonus −= pumpGain · 0.5 · |dh/dz| · dt` (неправильный ритм тормозит).
- `pumpBonus` затухает `pumpDecay` (0.6/с), максимум `pumpMax` (+8 м/с).
- Подсветка: правильный ритм — короткий бумажный «вжух»-штрих у доски и звук.

### 4.4 Прыжок
- `released` при `holdTime ≥ 0.12 с` → прыжок. `vy = jumpBase + jumpHold · min(holdTime, 0.6)` (`jumpBase` 5, `jumpHold` 8).
- Множитель вылета: с трамплина ×1.6, с гребня волны (если `x < 0` и движешься вправо, `heading > 10°`) ×1.4 — «вылет с губы».
- Гравитация `gravity` 18 м/с².
- Короткий тап (< 0.12 с) — ничего (чтобы случайные касания не прыгали).

### 4.5 Трюки в воздухе
- `spin += lean · spinRate · dt` (`spinRate` 540°/с). Визуал: поворот спрайта по Y (флип-кадры) + полный оборот = смена фаз 4 кадра.
- `hold` в воздухе = **грэб** (спрайт `grab`, +очки за время), но пока держишь — кружка дальше от тела: возмущения ×1.5.
- Очки: 180° = 200, 360° = 500, 540° = 900, грэб +100/0.25 с.

### 4.6 Посадка
- При касании: `spinErr = расстояние от spin до ближайшего кратного 360°` (180° тоже «чисто» — едем switch, но очков меньше на 30%).
- `clean = 1 − clamp((spinErr − 20°) / 50°, 0, 1)`, дополнительно ×0.5 если `hold` ещё зажат.
- `clean ≥ 0.85` → «ЧИСТО!», импульс в кружку 0; `0.4–0.85` → плеск по формуле `landImpulse · (1 − clean)`; `< 0.4` → спотыкание.

### 4.7 Спотыкание (и «накрыло»)
- Скорость −30% на 1.2 с, большой импульс в кружку (`hit`), тряска. Второе за 5 с → падение (в песочнице: респаун через 1 с, счётчик падений).

## 5. Кружка: вход физики жидкости (ключ всей механики)

Наклон в вираже **не плещет** — плещет только **изменение** наклона и внешние толчки.

```
leanAngle  = lean · 28°                      // как наклонён сёрфер с кружкой
leanSmooth = lowpass(leanAngle, sloshTau)    // sloshTau = 0.35 с
jerkTilt   = (leanAngle − leanSmooth) · jerkGain    // только «рывок», jerkGain 1.0
mugTilt    = jerkTilt + disturbances.roll · (1 − assist)
ax         = disturbances.ax + (Δheading/dt) · headingAx   // headingAx 0.15
→ MugLiquid.step(dt, ax, ay, mugTilt)
```
Смысл: плавный длинный вираж — пиво ровное. Резкая «восьмёрка» туда-обратно — плещет. Всё сразу понятно без обучения.

**Возмущения** (`disturbances`, сумма источников, как в §5.3 ТЗ уровня — переиспользовать `BalanceSystem`, если уже сделан):
| Источник | Когда | Сила (по умолчанию) |
|---|---|---|
| `faceChop` склон волны | `inPocket > 0` | шум ±`chopPocket` (5°) · inPocket, 4 Гц |
| `swellBump` зыбь | на гребне зыби | ±2° |
| `wake` кильватер бота | за ботом, 10 м | шум ±4°, 6 Гц |
| `bump` соперник/буй | столкновение | 18° + `ax` 1.0 |
| `landing` | посадка | см. §4.6 |

**Компенсация (необязательная, для мастеров):** игрок может гасить толчки встречным коротким наклоном — это уже заложено формулой (рывок `jerkTilt` противоположного знака складывается с возмущением). Ничего дополнительно не программировать, только проверить, что это работает.

`assist` (ползунок, 0–0.6, по умолчанию 0.3) — скрытое гашение возмущений для новичков.

## 8. Визуальная обратная связь (минимум для песочницы)

- Сёрфер кренится (`roll`), позы: `norma`, `turn` (зеркалить по знаку), `crouch` (пока hold), `jump`, `grab`.
- Брызги из-под доски, сильнее в кармане и в резком вираже.
- Speed lines при скорости > 32 м/с.
- HUD-кружка из Фазы 3.
- Стоп-кадры и типографика — НЕ нужны (используется toast «ЧИСТО!», «НАКРЫЛО», «НАКАЧКА»).

## 9. Приёмка

- Работает на iOS Safari и Android Chrome по HTTPS, гироскоп, фолбэк drag, клавиатура.
- 60 fps на среднем Android.
- Отчёт: ссылка/способ запуска на телефоне + JSON пресета по умолчанию + 30-секундное видео с телефона: карман, накачка, прыжок с трюком, кильватер.
- Дальше заказчик сам крутит ползунки и присылает лучший JSON.
