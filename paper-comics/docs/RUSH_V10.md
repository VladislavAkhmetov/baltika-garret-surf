# Крупный план и Кураж — V10

Эта версия приближает камеру и связывает существующие обгоны, волны и трамплины в более заметные серии действий.

## Изменения

- Герой вместе с серфом занимает примерно 29–31% высоты портретного экрана в контрольных сценах. Погоня пены больше не отдаляет камеру на шесть метров. В полёте камера плавно отступает и поднимается, оставляя место для переворота и посадки; горизонт остаётся ровным. Боковое сопровождение учитывает скорость поворота. Для широкого экрана сохранена большая дистанция.
- Два участка получили близкое окружение: скалы около 218–364 м и проход между скалами и пирсом около 623–795 м. Это видимые границы вне игровой полосы; новых невидимых столкновений нет. Скалы — отдельный PNG с прозрачностью; пирс использует существующие материалы бумажных объектов.
- Восемь линий крышек на воде и пять воздушных дуг над прямыми трамплинами. Водные линии обходят поверхности трамплинов. Воздушная дуга фиксируется при приближении и рассчитывается по скорости, высоте трамплина и гравитации прыжка. Сбор проверяется по реальной высоте героя; полная линия даёт дополнительную награду. Крышки не дают Кураж сами по себе.
- Кураж включается за три разных типа чистых манёвров с интервалом не более 6,5 секунды: ловля волны, обгон, близкий проход/прыжок над препятствием, воздушный трюк/посадка или карвинг/езда по следу. Повтор одного типа не заряжает дополнительные отметки. Кураж длится 3,6 секунды, даёт плавное ускорение и временный предел скорости 46 вместо 42, усиливает пену и звуковой акцент. Пролив от 1% сбрасывает серию и ускорение. Пауза останавливает таймеры.
- Вода светлее, белая пена на гребнях шире, след серфа заметнее. В повороте брызги летят наружу; посадка сильнее сгибает колени. Короткие брызги по краям экрана не закрывают центральный путь и отключены при reduced motion.
- Одновременно виден один текстовый сигнал: удар, непосредственная опасность, награда, итог цепочки, обучение или подсказка. Реплики персонажей ждут свободного окна. Поздняя награда больше не приклеивает очки к сообщению об ударе.

## Проверки

- `npm run test:rush`: достижимость всех шести крышек первого прыжка, честное начисление Куража, сброс/истечение/пауза/перезапуск, сбор крышек в воздухе без повторного начисления, согласованность сообщений, более 1000 кадров сопровождения по маршруту, 16 снимков на четырёх размерах экрана.
- `npm run test:race`: seed 42, доставка за 34,2 секунды с 72% напитка, четыре чистых обгона, десять прыжков/трюков, 36 крышек и два Куража. Соперники обходят физические трамплины.
- `npm run test:playthrough`: непрерывный заезд с отрисовкой, доставка с 90% напитка, четыре прыжка, два ухода от акулы и повторный запуск через интерфейс.
- `npm run test:controls`, `npm run test:cast-polish`, `npm run test:track-action`, `npm run test:serve`: управление, гироскоп с временным ручным перехватом, стопы на досках, трюки, след гидроцикла, тач и корректная загрузка CSS/ресурсов.

Снимки и отчёты находятся в `review/comics/rush/`, `review/comics/race/` и `review/comics/playthrough/`. Результаты автоматических пилотов подтверждают работоспособность; ощущение скорости и удобство настоящего гироскопа оцениваются на телефоне.
