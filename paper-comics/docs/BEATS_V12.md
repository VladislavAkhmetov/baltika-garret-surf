# События между крупными встречами — V12

`SurfBeats` дополняет трассу V11 короткими действиями на воде. События необязательны: игрок может собирать их бонусы, выбирать объезд или продолжать основную линию. Для них используются существующие бумажные материалы, крышки, чайки и звуки.

## Добавленные события

- Семь серий по три воротца с флажками: 48/96/142 м, 398/416/434 м, 512/531/550 м, 716/738/760 м, 822/846/870 м, 1038/1056/1074 м и 1224/1264/1304 м. Последняя серия перенесена на S-образный маршрут в V13; остальные первые два прохода предлагают поворот, последний возвращает на основную линию. Положение ворот фиксируется при старте с учётом маршрута данного seed.
- Точный проход между флажками собирает крышку и даёт 45 базовых очков в цепочку. Три успешных прохода в одной серии дают ещё 220 очков и тип карвинга для Куража. Промах не наносит урон; отдельные последующие крышки остаются доступны. Слишком высокий полёт над флажками не собирает крышку. Пройденные флажки меняют цвет.
- На 603 и 941 м стоят плавающие канаты из ярких поплавков. Прыжок с реальной высотой доски от 0,95 м даёт 180 очков и тип обхода опасности для Куража. Объезд за краем даёт 70 очков. Касание снимает 2,5% напитка и немного замедляет. Результат каждого каната фиксируется один раз. Новые соперники и подвижные опасности ждут, пока игрок пройдёт близкий канат.
- Четыре стаи по три чайки пролетают близко к герою около 188, 487, 811 и 1052 м. Пролёт сопровождается существующим звуком чаек. Птицы не наносят урон и заканчивают пролёт через 2,8 секунды. При reduced motion близкие пролёты скрыты.
- У бара стоит ряд из одиннадцати крышек и серия флажков с бонусом 250 очков. В V13 линия ведёт через три финишных виража между рифами; новые атаки здесь не запускаются.

Предупреждение о канате и прогресс серии используют существующее центральное сообщение. На экране сохраняется один текстовый сигнал. Герой остаётся крупным на воде; в боковом прыжке камера отступает дальше и быстрее сопровождает движение, чтобы доска помещалась при вращении.

## Проверки

- `npm run test:beats`: точный проход, пропуск, высота сбора, начисление один раз, прыжок/объезд/касание каната, пауза, сброс и reduced motion. Три полных заезда с активным сбором на seed 42/7/93 завершены с 75–100% напитка, 12–16 воротцами, 2–3 завершёнными сериями и 1–2 прыжками через канат. Сняты 12 кадров на портретном, небольшом и широком экране; ошибок загрузки и выполнения нет. Проверка пауз между действиями учитывает продолжающийся полёт, манёвр, близкую встречу и восстановление после трюка.
- `npm run test:rush`: камера проверена на 1015 кадрах маршрута с вращениями; герой и доска укладываются в допустимые границы. Сохранена достижимость всех шести крышек первого воздушного ряда, корректное начисление Куража и приоритет сообщения.
- `npm run test:race`: сохранены пять встреч, обход трамплинов, чистые обгоны и полное прохождение.
- `npm run test:playthrough`: непрерывный заезд с отрисовкой завершён с 79% напитка; повторный запуск через интерфейс сбрасывает состояние.

Снимки и отчёт новых событий находятся в `paper-comics/review/comics/beats/`. Автоматические прогоны проверяют достижимость и отсутствие конфликтов; удобство настоящего гироскопа оценивается на телефоне.
