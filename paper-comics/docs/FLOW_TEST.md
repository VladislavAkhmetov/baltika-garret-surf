# Три волны: прототип подхвата и траектории

Подсказка траектории, импульс подхвата, более отзывчивый курс и новая камера внедрены также в основной заезд. Общий рендер — `js/wave-ribbon.js`; теперь это тонкий пунктир, меняющий цвет по точности следования. В полном маршруте `TrickRoute` задаёт его положение один раз при старте, учитывая волны, неподвижные буи и трамплины. На основной трассе переключение доступно по `L` и в паузе, проверка — `npm run test:ribbon`. Этот короткий участок остаётся отдельным сравнением трёх волн без трамплинов.

Открыть `index.html?flowtest=1` на локальном сервере. Из корня репозитория: `npm run dev`, затем [тестовый участок](http://127.0.0.1:8080/paper-comics/index.html?flowtest=1). При запуске сервера из `paper-comics` адрес — [порт 8081](http://127.0.0.1:8081/index.html?flowtest=1).

## Что проверяем

Один фиксированный участок длиной 730 м: доступный заход на первый склон, широкая дуга на второй волне, высокий вылет с третьей и место для посадки. Активный заезд рассчитан на 20–30 секунд. Можно пройти без прыжков. Без руления участок проходится медленнее, волны сами не засчитываются.

Пунктир советует траекторию по реальной поверхности воды. Маленькие точки меняют цвет от красного к зелёному по расстоянию до линии и направлению доски; световые импульсы подсказки убраны. Вход на рабочий склон даёт физический импульс скорости, звук, брызги и приседание героя. Движение вниз по склону добавляет разгон; его можно сохранить для следующего захода. За пределами линии нет штрафа. Пунктир не участвует в физике, наградах и условиях ловли.

Прыжок запускается одним нажатием, трюк — вторым в воздухе. Баланс и вес на доске в этом режиме упрощены. Гироскоп не запрашивается. Погоня, соперники, препятствия, коллекция, задания и комиксные остановки отключены. Прогресс и рекорды полной игры не читаются и не записываются этим режимом.

Камера выше и смотрит ближе к воде. На экране остаются этап, скорость, прогресс, управление и короткая подсказка. На финише показываются фактически пойманные волны, максимальная скорость, чистые посадки и время; предыдущий заезд можно сравнить в той же сессии.

## Сравнение

- «С лентой» / «Без ленты» доступны перед стартом.
- Во время езды: кнопка «Лента» или `L`. Это меняет только визуал, без перезапуска.
- `R` или «Заново» запускают тот же участок.
- На финише можно сразу повторить с противоположным вариантом.
- Ссылка без ленты: `index.html?flowtest=1&ribbon=off`.
- Направление: `← →`, `A D`, экранные кнопки либо горизонтальное движение пальца по воде. `Пробел` / кнопка прыжка — вылет и трюк. `Esc` / `P` — пауза.

## Проверка

`npm run test:flow` проверяет прохождение через штатную физику без телепортации, три подхвата, добровольный вылет, трюк и посадку, идентичность симуляции с лентой и без, отсутствие записи в прогресс полной игры, переключение, паузу, перезапуск, расположение управления на четырёх размерах экрана, привязку геометрии к воде и отсутствие ошибок WebGL. Скриншоты и отчёт: `review/comics/flow-test/`.

Это браузерный прототип для оценки руками. Автопрогон подтверждает проходимость и правила; ощущение подхвата, удобство на физическом телефоне и предпочтение ленты требуют плейтеста.
