# Связанный заезд — V11

После крупного плана и Куража из V10 трасса получила последовательность встреч, физическую развилку и отдельный финал. `SurfSetpiece` координирует существующие системы по положению игрока и завершению манёвров. Управление остаётся у игрока.

## Ритм трассы

- На 155 м бабуля догоняет героя и выходит вперёд. Первый прямой трамплин остаётся на 226 м.
- На 264–339 м маршрут расходится. Слева проходит узкая линия между двумя скалами, справа — широкий обход. На каждой ветке есть крышки и указатель. Прежний боковой трамплин в этом месте отключён вместе с его подсказкой и подбором крышек.
- Чистый узкий проход даёт 250 базовых очков, импульс скорости и тип манёвра для Куража. Касание скалы снимает 8% напитка, замедляет героя и отменяет бонус; один камень не наносит повторный урон при скольжении вдоль него. Форма столкновения учитывает высоту доски. Основания скал уходят под воду.
- Первый гидроцикл включается после выхода из развилки, начиная с 343 м, и оставляет примерно 1,7 секунды до пересечения. Далее линия ведёт к прямому трамплину на 452 м. Тандем появляется после приземления, не раньше 520 м.
- Последующие встречи: диджей, Лола, повторный обгон бабули. Новая встреча ждёт посадки и восстановления игрока. Между появлениями соперников выдерживается минимум 2,8 секунды, между запусками подвижных опасностей — 2,5 секунды. Соперники заранее выбирают водный обход трамплина и держат его сторону до конца препятствия.
- На второй трети, 427–853 м, добавлены семь прибрежных скальных групп и восемь объёмных рифов по краям водного коридора. Пенистые кромки повторяют поверхность волн, основания рифов остаются неподвижными. Касание выступающего рифа снимает 4% напитка и немного гасит скорость, один риф наносит урон один раз за заезд. Прыжок выше его вершины проходит свободно. Входы трамплинов, посадочные полосы и слаломные ворота сохранены.
- На 1110 м стоит финальный трамплин на большой волне. Чистое приземление даёт дополнительную награду. Перед ним прекращаются новые встречи, преследующие акулы уходят, после 1145 м погоня пены заканчивается и не возобновляется. В V13 финиш продлён до 1360 м, сохранив положение остальных волн: после последней посадки начинается S-образный проход между рифами с ускорителями. Его поведение описано в `SPRINT_V13.md`.

## Камера и интерфейс

Герой сохраняет крупный масштаб на воде. В полёте камера немного отступает и быстрее сопровождает подъём, чтобы высокий финальный прыжок и боковое вращение помещались в кадре. Положение горизонта остаётся стабильным. Подсказки развилки и финала используют существующий приоритет сообщений; опасная пена выводит одно центральное предупреждение.

## Проверка

- `npm run test:setpiece`: два пути на seed 42, 7 и 93; шесть успешных доставок с 82–100% напитка, без касаний скал при следовании выбранной линии. Проверены награда за риск, интервалы встреч, реакция на гидроцикл, финальный вылет, тихий подход, пауза и сброс. Девять снимков на трёх размерах экрана.
- `npm run test:race`: пять встреч, три чистых обгона и восемь прыжков с трюками на seed 42; соперники не пересекают поверхности трамплинов. Проверены фиксированное намерение, начисление наград один раз, воздушное расхождение и 16 контрольных снимков.
- `npm run test:rush`: шесть из шести крышек первого воздушного ряда достижимы реальным прыжком; Кураж, пауза, сброс и приоритет сообщений работают. Камера проверена на 982 кадрах полного маршрута с вращениями и на 16 снимках четырёх размеров экрана.
- `npm run test:playthrough`: непрерывный заезд с отрисовкой завершён с 82% напитка; повторный старт через интерфейс сбрасывает напиток, волны и экран результата.
- `npm run test:action`: прохождение с трамплинами и по обходу, последствия езды без поворотов, погоня пены и предупреждение о близком гребне на четырёх размерах экрана.
- `npm run test:controls`, `npm run test:track-action`, `npm run test:serve`: сохранение настроек, временный ручной перехват гироскопа, мультитач, трюки, акулы, след гидроцикла, загрузка CSS и ресурсов.

Отчёты и снимки: `paper-comics/review/comics/setpiece/`, `race/`, `rush/`, `playthrough/`. Это проверки автоматическими пилотами и эмуляцией ввода; ощущение наклона и удобство управления на настоящем телефоне требуют игрового прогона на устройстве.
