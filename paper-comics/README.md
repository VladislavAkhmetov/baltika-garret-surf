# GARRET — НИ КАПЛИ!

Отдельная рабочая версия игры в стиле бумажных комиксов. Исходная v3 сохранена в родительском проекте.

## Запуск

Из этой папки: `npm run dev`. Открыть [локальную игру](http://127.0.0.1:8081/).

Обычный статический хостинг обслуживает `index.html`; сборка не нужна. Для гироскопа на телефоне требуется HTTPS. Локальный сервер предназначен для компьютера, а опубликованную HTTPS-копию можно открыть на телефоне. Публикация в рамках этой итерации не выполняется.

## Управление

- Телефон: нажать «Лови волну», разрешить датчики и держать телефон удобно во время калибровки. Наклон — направление. Кнопка «Присед» — сжатие ног в повороте. Отпускание на склоне — разгон, около гребня — вылет. В воздухе наклон вращает доску, удержание на подъёме даёт захват, удержание на снижении смягчает посадку. ◎ запоминает новую нейтраль.
- Без датчиков: слева drag направления, справа удержание/отпускание.
- Desktop: стрелки/A/D и пробел; мышью можно тянуть и отпускать. P/Esc — пауза. Поле квадратное.

Входи в пенную линию и держи плавную дугу, чтобы поймать разгон волны. Сжатие и разгибание работают в ритме поворота, а постоянное удержание не заменяет накачку. Согнутые ноги смягчают нагрузки на кружку; резкие повороты, кильватер и жёсткая посадка раскачивают пиво и могут пролить его через край. Отдельной кнопки сохранения пива нет.

## Документы и проверка

Актуальные правила и план: [PAPER_COMICS_SPEC.md](docs/PAPER_COMICS_SPEC.md). Сохранённые старые спеки — справочный контекст.

`npm run test:prototype` проверяет механику и снимает кадры в `review/comics/`. Тест использует Chrome через Puppeteer; можно задать `CHROME_PATH`. В автономной копии зависимости для тестов устанавливаются через `npm ci`. Для запуска игры npm-зависимости не нужны.

Дополнительные ракурсы героя, верхний плавник акулы и прозрачная бумажная рамка кружки сгенерированы встроенным image_gen и сохранены в `assets/comics/`; точные промпты находятся в `assets/comics/generation.json`. Жидкость внутри рамки рисуется из физического состояния, без набора дискретных уровней. Проверка на реальном телефоне остаётся необходимой для оценки задержки гироскопа, удобства касаний и FPS.
