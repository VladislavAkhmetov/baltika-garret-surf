# GARRET — НИ КАПЛИ!

Рабочий предрафт бумажных комиксов, итерация 3.3. Исходная v3 сохранена в родительском проекте; актуальные изменения находятся в paper-comics/.

## Запуск

Из этой папки: npm run dev. [Игра](http://127.0.0.1:8081/) · [Покадровый просмотр](http://127.0.0.1:8081/animation-lab.html).

Сборка не требуется: статический сервер обслуживает index.html. Для датчиков телефона нужны HTTPS и разрешение браузера. Локальный сервер слушает только компьютер; публикация не выполнялась.

## Первая глава

Старт → персонаж → локация → три сцены комикса → управление → заезд. Доступны Макс и бухта GARRET; Витя, Стас, Северный риф и Ночной порт закрыты. Тони обещает встречу у бара за мысом, аквабайк поднимает след, и начинается дорога через семь волн. Комикс можно листать назад или пропустить; сюжет не задерживает повторный заезд. Пауза и результат позволяют вернуться в меню.

Иллюстрация сюжета и три ракурса аквабайка созданы встроенным image_gen. Файлы: assets/comics/story-triptych-v1.png и jetski-directions-v1.png; точные промпты — generation-chapter-v1.json. Шрифты с кириллицей и лицензиями SIL OFL находятся в assets/fonts/; внешняя загрузка шрифтов игре не нужна.

## Управление

- Телефон: разрешить датчики и удобно держать телефон во время калибровки. Вбок — курс по склону, вперёд/назад — вес на нос/хвост. Повторная центровка ◎ находится в паузе.
- Без датчиков: тянуть пальцем или мышью по двум осям. Отпустить — вернуть управление к нейтрали.
- Клавиатура: ← → / A D — курс, ↑ ↓ / W S — вес, P/Esc — пауза. Desktop использует квадратное поле.
- Кнопка ↑ / пробел: держать для подготовки, отпустить для прыжка. Плавный курс и вес около центра смягчают посадку.
- На гребне доску раскачивают волна и инерция. Завал вправо — выруливай влево, и наоборот. Вес на нос/хвост усиливает раскачивание; для спасения верни его к центру.
- После неудачной посадки баланс восстанавливается управлением. Удержи маркер в центре около 0,42 с, чтобы заработать «Вырулил». При большом завале или без спасения за 3,4 с герой падает.
- Падение: −18 процентных пунктов пива, сброс комбо и возврат на свободную воду через 1,25 с. Маршрут, счёт и собранные крышки сохраняются; после возврата действует 2,5 с защиты от повторного удара. Прыжок недоступен во время спасения и падения.

Семь округлённых отдельных волн идут вдоль берега и чередуются со спокойными промежутками. Входи на склон, выбирай высоту, набирай скорость при спуске и переходи к следующей волне. Середина даёт основной разгон, гребень требует тонкого баланса. Аквабайки оставляют физический след, который можно подхватить для ускорения.

Две редкие акулы преследуют сзади и запаздывают на поворотах. После 6 с следует быстрый бросок. Оторвись на волне, смени линию или вовремя прыгни над заходом. Удар завершает встречу и отнимает 13% пива; бесконечных укусов нет.

## Экран, герой и пиво

Во время езды оставлены пиво, счёт, пауза, тонкий прогресс и одна кнопка прыжка. На гребне и при потере равновесия появляется компактная шкала баланса; при погоне — иконка плавника. Текстовые приборы доступны по адресу с ?debug=1, инструкции находятся в меню.

32 новые позы показывают героя со спины: он не оборачивается во время манёвров. Для каждого кадра заданы опора стоп и хват, пальцы перекрывают ручку бумажной кружки. Живая жидкость, пена и выплески связаны с тем же объёмом, что HUD и результат. Стопмоушен до 14 кадров/с при непрерывной физике 120 Гц.

Фронтальные ракурсы остаются только в редких аниме-вставках на гребне, в вершине высокого прыжка или при эмоциональном спасении. Диагональные панели, короткая остановка и замедление. Reduced motion сохраняет событие без остановки.

Новые оригиналы: assets/comics/hero-*-rear-v2.png. Генерация — встроенный image_gen; точные промпты и пути результатов записаны в assets/comics/generation-rear-v2.json. Покадровые якоря — hero-rear-anchors-v2.json. Старые атласы и крупные планы сохранены; их генерация описана в generation-animation.json. Изображения не перерисовываются скриптами: показ использует UV-кадры и отсечение соседнего фрагмента.

## Проверка

Правила и параметры: [PAPER_COMICS_SPEC.md](docs/PAPER_COMICS_SPEC.md).

npm run test:prototype — Chrome/Puppeteer: две оси управления, поверхность/разгон, катбэк/след/обгон, прыжок и посадка, погоня/отрыв/уклонение, пиво, 32 кадра, чистый HUD, монтаж, финиш и сброс. CHROME_PATH позволяет выбрать браузер. Отчёт и снимки — review/comics/.

npm run test:playthrough — полный заезд с обычным рендером, всеми персонажами, прыжками через пробел, финишем и повторным стартом через интерфейс. Отчёт — review/comics/playthrough/.

npm run test:chapter — весь путь через меню и комикс на 393×852, 360×640, 1240×900 и 844×390; закрытые варианты, пауза, reduced motion, активный баланс, посадка, спасение, падение, респаун и защита. Снимки и JSON — review/comics/chapter/. node scripts/build-chapter-review.cjs собирает пять листов для визуального осмотра. Итоги — docs/PLAYTEST_CHAPTER_01.md.

scripts/check-scenes.cjs снимает постановочные сцены мобильного и квадратного поля; scripts/check-frames.cjs — контактный лист всех поз. Эти снимки дополняют функциональные тесты. Зависимости нужны только для тестов; игра не требует сборки.

Датчики и FPS на физическом телефоне пока не проверены. Чувствительность и сложность предрафта требуют игрового прогона на устройстве.
