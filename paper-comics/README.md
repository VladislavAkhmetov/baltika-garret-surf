# GARRET — НИ КАПЛИ!

Версия **Paper comics**: бумажный игровой интерфейс, четыре страницы комикса и заезд по семи волнам.

## Запуск

Из корня проекта: `npm run dev`. [Открыть игру](http://127.0.0.1:8080/paper-comics/index.html).

Из папки paper-comics: `npm run dev`, адрес http://127.0.0.1:8081/. Сборка не требуется.

## Меню и история

Главное меню содержит только название, героя и «Играть». На общем бумажном фоне экрана выбора остаются герой, открытка бухты, стрелки и «Продолжить». Сложность переключается в паузе.

Герой и локация выбираются на одном экране стрелками. Доступны Макс и бухта GARRET. Остальные варианты закрыты; просмотр закрытого варианта блокирует запуск.

Тони бросает Максу вызов: довезти бокал Garret от дальнего мыса до стойки через семь штормовых волн. На хвосте доски обнаруживается ворчливый краб Клешня, самопровозглашённый штурман. Борис принимает ставки и поднимает волну на гидроцикле. На финише ждёт кубок бухты.

Комикс состоит из четырёх страниц, каждой с отдельными панелями действия и крупного плана, большой репликой, именем говорящего и навигацией назад/вперёд. Его можно пропустить. Цель: пройти маршрут из семи волн и довезти не меньше 30% бокала. Первые три пойманные волны заполняют коллекцию; коллекция и отдельные крышки дают бонусы, но не блокируют кубок.

Клешня сидит на хвосте доски ближе к камере, немного сбоку от ног Макса. При повороте кренится вместе с доской, в прыжке поднимает клешни. Отдельная бумажная плашка показывает его реплики при разливе, появлении акулы, успешном побеге, близком увороте и трюках. Повторные реплики ограничены по частоте; тревога об акуле имеет приоритет. На победном экране краб в очках сидит на бокале, при проигрыше выжимает мокрую клешню.

После последней страницы или «Пропустить» заезд начинается сразу. Обучение идёт на воде: одна короткая подсказка и выделенные кнопки, реакция на поворот, отпускание, ловлю волны, удержание прыжка, посадку и восстановление баланса. Первые повороты и ещё не освоенное восстановление слегка замедляют время. Освоенные действия не повторяются при перезапуске заезда в текущей сессии; прыжок остаётся необязательным.

## Управление и сложность

- Курс: короткие нажатия ← → / A D или бумажные кнопки внизу.
- Прыжок: удерживать пробел / кнопку ↑ и отпускать. Для мягкой посадки отпустить поворот и перенос веса.
- На маршруте появляются три отдельные высокие волны-трамплина. Их положение меняется при новом заезде. Отпусти прыжок возле вершины; повторное нажатие пробела / ↻ в воздухе запускает вертушку на 360°. Чистая посадка даёт 600 базовых очков с текущими множителями. Незавершённое вращение или наклон при посадке требуют поймать баланс.
- Вес на доске: ↑ ↓ / W S, движение пальца вверх/вниз или наклон телефона. В первом заезде достаточно курса и прыжка.
- Мышь/палец по воде: движение вбок задаёт курс; отпускание возвращает управление к нейтрали.
- Телефон: гироскоп калибруется при запуске; повторная центровка доступна в паузе. Без доступа к датчикам работают кнопки и перетаскивание.
- Пауза: P / Esc или бумажная кнопка Ⅱ.

**Обычная сложность** выбрана по умолчанию. Курс плавнее, гребень менее резкий, восстановление баланса допускает до пяти секунд и красное предупреждение перед падением. Подсказки показывают направление к склону, опасности и подготовку посадки. Команда «прямо» не использует стрелку вверх.

**Высокая сложность** сохраняет быстрый курс и сильную раскачку; на восстановление — 3,4 секунды. На гребне и после жёсткой посадки нужно управлять против завала, затем отпустить поворот и удержать маркер в центре 0,42 секунды. Нейтральное управление само не завершает спасение.

Падение отнимает 18 процентных пунктов пива и сбрасывает комбо. Через 1,25 секунды доска возвращается на свободную воду с защитой 2,5 секунды. Прогресс, очки и крышки сохраняются. Один знакомый сёрфер может столкнуться с игроком только один раз за заезд.

## Визуал

Бумажные подложки, комикс, новый лысый Борис в трёх ракурсах и цельный вырез города созданы встроенным image_gen. Точные промпты и пути: [generation-chapter-v2.json](assets/comics/generation-chapter-v2.json). Новая синяя доска, четыре позы Клешни и обновлённый комикс с крабом на хвосте: [generation-wager-v3.json](assets/comics/generation-wager-v3.json). Исходные PNG сохранены; игровые позы и изображения результатов используют кадрирование атласа при отображении.

Прежний кудрявый аквабайкер сохранён в assets/comics/jetski-directions-v1.png. Игровой герой использует прежние 32 позы со спины. Кружка, пена и потеря жидкости связаны с HUD и результатом. Шрифты с кириллицей хранятся локально.

## Проверки

```
npm run test:prototype
npm run test:chapter
npm run test:novice
npm run test:playthrough
npm run test:wager
npm run test:airwaves
```

Результаты, границы проверки и пути скриншотов: [PLAYTEST_PAPER_COMICS_V2.md](docs/PLAYTEST_PAPER_COMICS_V2.md).

`test:wager` проверяет новую историю на четырёх размерах экрана, привязку Клешни к хвосту, позы прыжка и поворота, реплики и их приоритеты, сброс при перезапуске и обе реакции на финиш. Для 30% проверяется победа; 29,9% дают проигрыш и отображаются как 29%, чтобы округление не противоречило исходу пари. Снимки и отчёт: `review/comics/wager/`.

`test:airwaves` проверяет точки опоры всех 32 поз, обычный и высокий прыжок, запуск вращения клавиатурой и кнопкой, бонус после посадки, жёсткую посадку и сброс состояния. Экраны заезда и обоих результатов сняты на четырёх размерах; результат помещается без прокрутки. Кадры и числовой отчёт: `review/comics/airwaves/`.

`node paper-comics/scripts/build-chapter-review.cjs` из корня собирает пять листов визуального обзора. Каталог review хранит локальные снимки и игнорируется Git.
