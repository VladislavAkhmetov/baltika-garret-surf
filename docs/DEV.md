# DEV: Руководство разработчика и тестирование

## 1. Запуск и локальный сервер
Игра работает как с `file://`, так и через любой статический веб-сервер.

### Запуск с локального сервера:
```bash
npx http-server . -p 8080
```

### Тестирование гироскопа на телефоне (требуется HTTPS):
Браузеры (особенно Safari на iOS) блокируют `DeviceOrientation` и `DeviceMotion` на незащищённых HTTP-соединениях.

**Вариант A — HTTPS с самоподписанным сертификатом:**
```bash
npx http-server -S -C cert.pem -K key.pem -p 8443
```

**Вариант B — Localtunnel (рекомендуется для быстрого теста с телефона):**
```bash
# Терминал 1: запускаем локальный сервер
npx http-server . -p 8080

# Терминал 2: открываем публичный HTTPS-туннель
npx localtunnel --port 8080
```
Откройте полученный URL (https://...) на мобильном устройстве и выдайте разрешение на доступ к датчикам движения при старте заезда.

## 2. Параметры URL для отладки и ревью
- `?debug=1` — отображение оверлея FPS, текущей секции, пройденной дистанции (м), скорости (м/с), состояния кружки (level, foam, edge spill).
- `?section=<id>` — немедленный старт с указанной секции (`tutorial`, `ramp1`, `rivals`, `bay`, `refill`, `barrel`, `mega`, `finish`).
- `?seed=<n>` — фиксированный выбор вариантов секций и спавна (воспроизводимость).
- `?input=swipe|buttons|gyro` — принудительный выбор схемы управления.
- `?fx=<word>` — мгновенный вызов стоп-кадра с указанным словом (например, `?fx=ЧИСТО!`, `?fx=ЗОЛОТО!`, `?fx=В ТРУБЕ!`) для арт-ревью.

```bash
node scripts/test_game.js
```
